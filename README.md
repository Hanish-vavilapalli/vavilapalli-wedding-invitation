# Marigold Wedding Invitation

REFERENCE IMAGE ANALYSIS + PNG ANIMATION IMPLEMENTATION

I have already uploaded multiple reference images of my desired traditional South Indian wedding invitation design.

IMPORTANT: Use my uploaded reference images directly as the visual source of truth. Do not ask me to upload them again.

1. STUDY THE REFERENCE IMAGES

Carefully inspect every uploaded reference image.

Identify and recreate:

Exact cream textured background.

Faint temple watermark.

Top hanging yellow and orange marigold strings.

Green mango-leaf bunches hanging from flower strings.

Large banana plants on the left and right sides.

Pink hanging flower buds.

Green decorative foliage.

Bottom floral arrangements.

Traditional brass kalash.

Traditional temple and wedding illustrations.

Match the original placement, proportions, colours, spacing and overall composition as closely as possible.

Do not redesign or modernize these decorations.

2. USE INDIVIDUAL TRANSPARENT PNG ASSETS

The uploaded images show the desired appearance, but I do NOT want to use them as flattened backgrounds for the animated decorations.

Use individual transparent PNG assets for each decorative element.

Examples:

Each banana leaf must be a separate PNG.

Each mango-leaf bunch must be separate.

Each flower must be separately positioned.

Each hanging garland must be a separate element.

Each pink flower bud must be a separate element.

Each foliage branch must be separate.

Preserve transparent backgrounds.

Do not use a single composite AI-generated plant or decoration image.

3. INDEPENDENT ANIMATION

Every moving PNG must have its own animation controls.

Banana leaves:

Independent rotation.

Natural bending.

Subtle tip movement.

Different speeds and delays.

Realistic gentle breeze.

Marigold garlands:

Independent swinging.

Different animation timings.

Natural hanging movement.

Mango leaves:

Subtle independent swaying.

Side foliage:

Gentle leaf movement.

Do not animate an entire group as one object.

4. EXACT VISUAL COMPOSITION

Follow the uploaded references:

TOP:
Hanging marigold strings with green mango-leaf bunches.

LEFT AND RIGHT:
Large banana leaves, green branches and pink flower buds.

CENTER:
Clear wedding information over the cream background and faint temple watermark.

BOTTOM:
Symmetrical flower arrangements and brass kalash.

Maintain the same decorative composition throughout every website section.

5. VERIFICATION

Before completing the website, verify:

The uploaded references were actually used.

Individual transparent PNG assets are present.

Each banana leaf is a separate image element.

Every moving leaf has independent animation settings.

Every garland has independent movement.

Decorations match the reference composition.

No static composite image replaces the animated elements.

All animations work on mobile screens.

If an exact PNG asset is unavailable, identify it instead of pretending it exists.

FINAL REQUIREMENT

My uploaded images define the visual design.

Recreate their traditional wedding atmosphere as closely as possible.

I want a layered, realistic, animated wedding environment, not a static AI-generated picture.

Do not finish until the actual implementation has been visually tested.
